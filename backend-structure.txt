# Архитектура бэкенда (Supabase)

## Обзор
Бэкенд для формы обратной связи реализован на **Supabase** (BaaS-платформа).
Серверная часть на Версель — вся логика работает на клиенте через Supabase JS SDK.

## Компоненты

### 1. Клиентская часть (script.js)
- Подключение через CDN: `<script src="https://cdn.jsdelivr.net/npm/@supabase/supabase-js@2"></script>`
- Инициализация клиента:
  ```javascript
  const supabaseClient = window.supabase.createClient(SUPABASE_URL, SUPABASE_ANON_KEY);
  ```
- URL: https://zfxujjrfphkgqpilnrec.supabase.co

### 2. База данных (PostgreSQL)
Таблица: `feedback_messages`

| Поле          | Тип         | Описание                              |
|---------------|-------------|---------------------------------------|
| id            | UUID        | Первичный ключ (автогенерация)        |
| created_at    | TIMESTAMPTZ | Дата/время отправки (авто)            |
| name          | TEXT        | Имя отправителя (обязательно)         |
| email         | TEXT        | Email отправителя (обязательно)       |
| message       | TEXT        | Текст сообщения (обязательно)         |
| consent_given | BOOLEAN     | Согласие на обработку данных          |
| status        | TEXT        | Статус: 'new' | 'read' | 'replied'   |

Индекс: `idx_feedback_created_at` — для сортировки по дате.

### 3. Логика отправки (script.js, строки 76-112)
1. Сбор данных из формы (имя, email, комментарий, чекбокс согласия)
2. Валидация:
   - Проверка согласия на обработку персональных данных
   - Проверка заполненности обязательных полей
3. Вставка в БД через `.from('feedback_messages').insert({...})`
4. Обработка ответа:
   - Успех → очистка формы + уведомление
   - Ошибка → вывод alert с сообщением

## Безопасность
- Используется **anon key** (публичный ключ для клиента)
- RLS (Row Level Security) должен быть настроен в панели Supabase
- Чекбокс согласия — обязательное поле (HTML + JS-валидация)

## Файлы
- `script.js` — клиентская логика отправки
- `index.html` — форма + подключение Supabase CDN
- `database/migrations/001_create_feedback_messages.sql` — миграция БД
