# Подробное описание бэкенда (Supabase)

## 1. Подключаемые библиотеки

### @supabase/supabase-js (версия 2.x)
**Файл:** `package.json`
```json
"dependencies": {
  "@supabase/supabase-js": "^2.0.0"
}
```

**Подключение в HTML:** `index.html` (строка ~230)
```html
<script src="https://cdn.jsdelivr.net/npm/@supabase/supabase-js@2"></script>
```

**Что делает библиотека:**
- Предоставляет JavaScript-клиент для работы с Supabase
- Позволяет выполнять CRUD-операции (Create, Read, Update, Delete) с базой данных
- Обрабатывает аутентификацию, авторизацию, сетевые запросы
- Работает через REST API или Realtime-подписки

## 3. Обработчик отправки формы

**Файл:** `script.js` (строки 85-127)

```javascript
if (contactForm) {
  contactForm.addEventListener('submit', async (e) => { ... });
}
```

### 3.1. Предотвращение стандартной отправки
```javascript
e.preventDefault();
```
**Назначение:** Отменяет стандартную отправку формы (перезагрузку страницы)

---

### 3.2. Сбор данных из формы

```javascript
const nameInput = contactForm.querySelector('input[type="text"]');
const emailInput = contactForm.querySelector('input[type="email"]');
const commentInput = contactForm.querySelector('textarea');
const privacyCheckbox = document.getElementById('privacy');

const name = nameInput.value.trim();
const email = emailInput.value.trim();
const comment = commentInput.value.trim();
const privacyChecked = privacyCheckbox.checked;
```

**Используемые методы DOM:**
- `querySelector()` — находит элемент по CSS-селектору
- `.value` — получает значение поля
- `.trim()` — удаляет пробелы по краям строки
- `.checked` — возвращает true/false для чекбокса

---

### 3.3. Валидация данных

#### Проверка согласия:
```javascript
if (!privacyChecked) {
  alert('Пожалуйста, подтвердите согласие на обработку персональных данных');
  return;
}
```

#### Проверка заполненности полей:
```javascript
if (!name || !email) {
  alert('Пожалуйста, заполните все поля');
  return;
}
```

**Функция `alert()`** — стандартный браузерный диалог

---

### 3.4. Отправка данных в Supabase

```javascript
const { data, error } = await supabaseClient
  .from('feedback_messages')
  .insert({
    name: name,
    email: email,
    message: comment,
    consent_given: true,
    status: 'new'
  });
```

### Метод `.from(table)`
**Назначение:** Указывает таблицу для операции
**Параметр:** `'feedback_messages'` — имя таблицы в БД
**Возвращает:** Объект запроса с методами `.insert()`, `.select()`, `.update()`, `.delete()`

### Метод `.insert(values)`
**Назначение:** Вставляет новую запись в таблицу
**Параметр:** Объект с данными для полей таблицы
**Возвращает:** Promise с результатом `{ data, error }`

| Поле | Значение | Тип в БД |
|------|----------|----------|
| `name` | Введённое имя | TEXT |
| `email` | Введённая почта | TEXT |
| `message` | Текст комментария | TEXT |
| `consent_given` | `true` (всегда) | BOOLEAN |
| `status` | `'new'` (новый статус) | TEXT |

**Автоматически заполняемые поля (не указаны в insert):**
- `id` — генерируется UUID (по умолчанию в БД)
- `created_at` — текущая дата/время (по умолчанию в БД)

---

### 3.5. Обработка результата

#### Успешная отправка:
```javascript
if (error) {
  throw error;
}

alert(`Спасибо, ${name}! Ваше сообщение отправлено.`);
contactForm.reset();
console.log('Сообщение сохранено в БД:', data);
```

**Методы:**
- `alert()` — показывает уведомление пользователю
- `contactForm.reset()` — очищает все поля формы
- `console.log()` — выводит данные в консоль разработчика

#### Обработка ошибок:
```javascript
} catch (err) {
  console.error('Ошибка отправки:', err);
  alert('Произошла ошибка при отправке. Попробуйте позже.');
}
```

**Методы:**
- `console.error()` — выводит ошибку в консоль
- `alert()` — показывает сообщение об ошибке

## 4. Структура таблицы (База данных)

**Файл:** `database/migrations/001_create_feedback_messages.sql`

### CREATE TABLE
```sql
CREATE TABLE IF NOT EXISTS feedback_messages (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  name TEXT NOT NULL,
  email TEXT NOT NULL,
  message TEXT NOT NULL,
  consent_given BOOLEAN NOT NULL DEFAULT false,
  status TEXT DEFAULT 'new' CHECK (status IN ('new', 'read', 'replied'))
);
```

### Поля таблицы:

| Поле | Тип | Описание | Значение по умолчанию |
|------|-----|----------|----------------------|
| `id` | UUID | Уникальный идентификатор | `gen_random_uuid()` |
| `created_at` | TIMESTAMPTZ | Дата и время создания | `NOW()` |
| `name` | TEXT | Имя отправителя | — (обязательно) |
| `email` | TEXT | Email отправителя | — (обязательно) |
| `message` | TEXT | Текст сообщения | — (обязательно) |
| `consent_given` | BOOLEAN | Согласие на обработку | `false` |
| `status` | TEXT | Статус обработки | `'new'` |

### Ограничения (constraints):
- `PRIMARY KEY` — первичный ключ (уникальность id)
- `NOT NULL` — поле обязательное
- `CHECK (status IN (...))` — статус может быть только из списка

### Индекс
```sql
CREATE INDEX IF NOT EXISTS idx_feedback_created_at ON feedback_messages(created_at DESC);
```
**Назначение:** Ускоряет сортировку по дате (новые сверху)

## 9. Возможные расширения

### Методы Supabase, которые можно добавить:

| Метод | Назначение |
|-------|------------|
| `.select()` | Получить все сообщения из БД |
| `.update()` | Изменить статус сообщения (new → read) |
| `.delete()` | Удалить сообщение |
| `.eq('status', 'new')` | Фильтрация по статусу |
| `.order('created_at', { ascending: false })` | Сортировка по дате |

### Пример получения сообщений:
```javascript
const { data, error } = await supabaseClient
  .from('feedback_messages')
  .select('*')
  .eq('status', 'new')
  .order('created_at', { ascending: false });
```
