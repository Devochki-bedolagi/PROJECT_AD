# Local Music Party

Мобильное приложение для поиска локальных музыкальных мероприятий в вашем городе.

## 🎯 О проекте

**Local Music Party** — это платформа для музыкальных событий, которая объединяет:
- 🎵 Афишу музыкальных мероприятий
- 🗺️ Карту ближайших событий
- 🎤 Поддержку локальных артистов
- 💰 Бонусную программу для пользователей

## 📬 Форма обратной связи

На сайте реализована форма обратной связи с сохранением данных в базу данных Supabase.

### Как это работает:
1. Пользователь заполняет форму (имя, email, сообщение)
2. Данные валидируются на клиенте
3. Отправка в базу данных Supabase через REST API
4. Сообщение сохраняется в таблице `feedback_messages`
