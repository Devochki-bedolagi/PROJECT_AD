# Как работает форма обратной связи (простыми словами)

## Схема работы

1. **Пользователь заполняет форму на сайте**
   - Вводит имя, почту, пишет сообщение
   - Ставит галочку "Согласен на обработку данных"
   - Нажимает кнопку "Отправить"

2. **Сайт отправляет данные в Supabase**
   - Supabase — это готовый облачный сервис (как Google Таблицы, но для разработчиков)
   - Данные улетают по интернету в базу данных Supabase

3. **Данные сохраняются в таблицу**
   - Каждая отправка — новая строка в таблице `feedback_messages`
   - Как в Excel: столбцы = имя, почта, сообщение, дата, статус

4. **Вы видите сообщение об успехе**
   - Если всё ок → появляется "Спасибо! Ваше сообщение отправлено"
   - Если ошибка → "Произошла ошибка, попробуйте позже"

## Где что находится

| Что                    | Где лежит                          |
|------------------------|------------------------------------|
| Форма на сайте         | `index.html` (секция "Обратная связь") |
| Логика отправки        | `script.js` (строки 76-112)        |
| База данных            | Supabase (облако, не в проекте)    |
| Структура таблицы      | `database/migrations/001_....sql`  |

## Что происходит "под капотом"

```
Пользователь → заполняет форму → нажимает "Отправить"
     ↓
script.js → собирает данные → проверяет поля
     ↓
Supabase → сохраняет в таблицу feedback_messages
     ↓
script.js → показывает "Спасибо!" или ошибку
```
